# Work Organizer

A complete management tool for your various role dimensions, tasks and recurring meetings with an Adidas-inspired dark theme.

## 🚀 Access the App

**Live URL:** [https://rawatvin.github.io/work-organizer/](https://rawatvin.github.io/work-organizer/)

## ✨ Features

- **Role Dimensions Management**: Define and track your different professional roles with 180-day plans
- **Task Management**: Create, organize, and track tasks across multiple views (Grid, Timeline, Kanban)
- **Recurring Meetings**: Schedule and track recurring meetings with notes and action items
- **Conversation Tracking**: Link conversations to specific tasks and roles
- **AI Integration**: Gemini AI integration for meeting summaries and insights
- **Time Tracking**: Track time spent on tasks and updates
- **Multiple Views**: Switch between different visualization modes
- **Dark Theme**: Professional Adidas-inspired design

## 📱 How to Use

1. **Open the app** in your browser using the URL above
2. **Your data is private**: All data is stored in your browser's localStorage (private to you)
3. **No login required**: Start using immediately
4. **Data persistence**: Your data stays saved in your browser
5. **Export/Import**: Use the export/import buttons to backup or transfer your data

## 💾 Data Storage

- All data is stored locally in your browser's localStorage
- Each user has their own separate data
- **Important**: If you clear your browser cache/data, your tasks will be lost
- **Backup regularly**: Use the Export button to save your data

## 🔄 Backup Your Data

1. Click the **Export** button in the top right
2. Save the downloaded JSON file
3. To restore: Click **Import** and select your backup file
